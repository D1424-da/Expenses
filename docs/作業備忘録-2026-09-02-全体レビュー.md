## 1. SEO

### 1-1. 内部リンクの行き先がトップ1つ 〔構造・最重要〕

Search Console「上位のリンクされているページ - 内部」が、行き先1件・48本。
約100ページのサイトで、記事間リンクが Google のグラフに載っていない。

着手前の「検索対象に残した18本」の束は、**被リンク0本が8本・発リンク0本が
9本**だった。`blog.html` からの1本しか入り口が無い記事が半数近くあった。

対処: `claude/kept-article-links`（親 `receipt-cluster-links` を含む）。
両方で被リンク0・発リンク0がどちらも0本になる。`tests/test_internal_links.py`
が孤立と行き止まりを固定する。

親ブランチだけでは足りない理由: リンク元60ファイルのうち58が noindex の記事。
Google は長期の noindex ページのクロール頻度を落とすため、その経路は持続しない。
**効くのは Google が見続けるページ＝残した18本どうしのリンク。**

### 1-2. 「クロール済み - インデックス未登録」84件の正体 〔読み方〕

Coverage Drilldown（9/2 取得。最終クロール 7/27〜8/25）を分類した。

| 分類 | 件数 | 評価 |
|---|---|---|
| 301 設定済み URL | 43 | 残骸。再クロールで消える |
| `searchExclude`（noindex, follow） | 28 | 8/25 の noindex 適用**前**のクロール。「noindexで除外」へ移る |
| カテゴリページ | 5 | 1-3 を参照 |
| `sitemap.xml`・法務ページ | 5 | 実害なし |
| **検索対象として残した記事** | **3** | **本当の問題** |

3件は `family-recipe-share` / `food-budget-app` / `kakeibo-app-compare`。
`CLAUDE.md` がクリック実績のある3本として挙げるうち2本がここに含まれ、
3本とも着手前は「他の残した記事からリンクを受けていない」側にいた（1-1）。

**このデータは 8/28 のデプロイを1件も反映していない。** 増減の解釈はまだできない。

## 2. アクセシビリティ

### 2-1. アプリ側（`login.html`）は良い状態

img 1個・alt あり。button 97個すべて読み上げ名あり（`display:none` の隠し3個は
意図的）。`role=dialog` / `aria-modal` 11/11。`prefers-reduced-motion`・
`focus-visible`・スキップリンク・`lang="ja"` あり。8/28 の4a〜4d は反映済み。

### 2-2. ブログ側にコントラスト不足が残っている 〔要対応・測定後〕

アプリ側はダークの `--muted` を直したが、**ブログは別系統の CSS**（`tokens.css`・
`landing.css`）で未対応。Lighthouse の実測:

| ページ | 要素 | 比 | 色 |
|---|---|---|---|
| `blog.html` | `.blog-card-date` ほか | **3.05** | #7A9B87 / #FFFFFF |
| `blog.html` | `.featured-la` | **2.69** | #D4900A / #FFFFFF |
| `blog.html` | `.featured-t` | 3.27 | #B87A00 / #FEF3DA |
| 記事 | `h3`（濃緑ボックス内） | **1.73** | #12200F / #1A4D2E |
| 記事 | `p`（補助文） | 2.83 | #879987 / #F7F8F4 |
| 記事 | `.am-reading-time` | 3.9 | #6C826C / #F7F8F4 |

`h3` 1.73:1 は濃緑の背景に近黒の見出しで、ほぼ読めない。基準は 4.5:1
（大きな文字は 3:1）。`blog.html` の a11y 89 はこれが原因。

### 2-3. 44px 未満と推定される押せる要素 〔小〕

CSS からの推定（実測ではない）。44px を宣言する規則に含まれるものは除外済み。

8/28 の「44px ルールが半分だけ適用されている」の残り。どれも共通ルールの列挙に
足すだけで済む。
